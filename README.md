# RentACar

Car rental website - student project.

## Step 1: HTML and CSS (current step)

The website is built with simple HTML and CSS only. All pages are linked, so you can click through the whole site. There is no JavaScript and no database yet.

How to open: double-click `index.html`, or open the folder in VS Code and use **Live Server**.

### Public pages

- `index.html` - home page
- `cars.html` - all cars
- `booking.html` - book a car
- `about.html`, `terms.html`, `contact.html`, `photo-credits.html`
- `login.html`, `signup.html`

### Dashboard (admin)

- `dashboard.html` - overview
- `dashboard-cars.html` - cars list
- `dashboard-add-car.html` - add a car
- `dashboard-reservations.html` - reservations
- `dashboard-clients.html` - clients
- `dashboard-locations.html` - locations

### CSS

- `style.css` - styles for all pages
- `dashboard.css` - extra styles for the dashboard

Car photos are in `images/cars/`. Reservations, clients and locations will appear in the dashboard after the database is connected.
